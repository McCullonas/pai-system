## Deep Dive Process

When Andy asks for a "deep dive" on a specific city:

1. Check this file for the city's local transport URL
2. Use WebFetch to scrape the city's transport site for current information
3. Also check seat61.com for the relevant country page — it often has local transport tips
4. Use WebSearch for "[city name] public transport visitor guide 2026" for current info
5. Compile: metro/tram map overview, key lines for tourists, ticket types, passes, airport connections, tips
6. Present conversationally — Mark knows this stuff
